# Lever

A control station (interlocking) for model railways, for Windows 10 and 11. Lever shows track
diagrams of the layout and lets an operator throw turnouts, set signals, see track occupancy and
set routes. It talks directly to a Z21-compatible central unit over the local network: no server,
no accounts.

Lever is the companion to [Throttle](https://github.com/MatteZ02/throttle), the mobile driving
app. Each works without the other.

**Status:** early development (Phase 0). See [docs/architecture.md](docs/architecture.md) and
[docs/development.md](docs/development.md).
